1. Entity-Relationship (ER) Diagram

Database Architecture

Illustrates the database relational schema: USERS (credentials & RBAC), BLOCKED_IPS (quarantined IP records with self-healing TTL countdowns), ATTACK_EVENTS (DDoS forensics audit trail), and TRAFFIC_LOGS (telemetry ingestion). 

erDiagram
    USERS {
        int id PK
        string name
        string email UK
        string password_hash
        string role
        datetime created_at
    }

    BLOCKED_IPS {
        int id PK
        string ip_address
        string reason
        string pattern_detected
        datetime blocked_at
        datetime expires_at
        int is_active
    }

    ATTACK_EVENTS {
        int id PK
        string pattern_name
        string source_ip
        string target_endpoint
        int request_count
        string severity
        text details
        datetime timestamp
    }

    TRAFFIC_LOGS {
        int id PK
        string client_ip
        string method
        string endpoint
        int status_code
        float response_time_ms
        string user_agent
        datetime timestamp
    }

    USERS ||--o{ BLOCKED_IPS : "manually unblocks"
    ATTACK_EVENTS ||--|| BLOCKED_IPS : "triggers quarantine"
    TRAFFIC_LOGS }o--o| ATTACK_EVENTS : "evaluated into"
